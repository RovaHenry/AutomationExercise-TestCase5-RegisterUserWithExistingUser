# AutomationExercise-TestCase5-RegisterUserWithExistingUser
Test Case 5: Register User With Existing User

This repository contains the implementation and documentation of Test Case 5 from Automation Exercise: "Register User With Existing User."

Overview

The test case validates the application's behavior when a user attempts to register with an email address that is already registered. This ensures the registration functionality correctly handles duplicate email addresses by displaying appropriate error messages without creating duplicate accounts.

Steps Covered:

1. Navigate to the application and open the "Signup/Login" page.
2. Enter an already registered email address and name in the respective fields.
3. Click on the "Signup" button.
4. Verify that an appropriate error message is displayed, indicating the email address is already registered.

Tools & Technologies Used: Selenium WebDriver, Mocha

Programming Language: JavaScript

Browser: Google Chrome
